# 携帯ごみポーチ × ハイタッチチャーム — 市場リサーチと製品コンセプト

調査日: 2026-08-02

## 0. 出発点（アイデアの整理）

- 街でごみを拾いたいが「持ち歩くのが億劫」で結局拾わない、という自分の実体験が起点
- 左ポケットに入るサイズ。ゴムっぽい / シリコンっぽい、握れる手触り
- 蓋・チャームが「ハイタッチの手」「ドラゴンの爪みたいな手」「犬の耳」
- 持ち主同士が出会ったらチャームでハイタッチできる
- 「犬を飼っています」というさりげないアピールになる
- 自分が拾った街のごみも、犬のうんちも、両方入る

**結論の先出し**: 入れ物としては既存品が山ほどある。チャームも既にある。
だが「街ごみ＋犬のうんち兼用」×「持ち主同士のインタラクション」の組み合わせは
直接の競合が見つからなかった。**守れるのは容器ではなく、儀式（ritual）とブランド**。

## 2. 作るとしたら — 製品コンセプト

### 2-1. ポジショニング（これが一番大事）

**「うんち袋ホルダー」として売ってはいけない。**

理由は3つ:
1. カテゴリが価格競争済み。中国OEMが即コピーできる
2. 「うんち」ブランディングだと、バッグに付けて見せたくない＝チャーム戦略と矛盾する
3. TAMが犬の飼い主に閉じる

代わりに **「令和の携帯灰皿」＝街をちょっときれいにする人のためのポケットごみ箱** として置く。
- 犬の飼い主は**ビーチヘッド**（毎日歩く・すでに持ち歩く習慣がある・可処分所得が高い）
- 市場は追い風: 犬の飼育頭数 682万頭で下げ止まり（[ペットフード協会 2025年調査](https://midori-ikimono.com/2025/12/22/petfoodkyokai2025/)）、
  ペット関連市場は2025年度 1兆9,257億円 → 2027年度に2兆円超の予測（[矢野経済研究所](https://www.yano.co.jp/press-release/show/press_id/3906)）
- そこからプロギング層・ランナー・親（子どものごみ）・アウトドアへ横に広げられる

### 2-2. 構造 — 「共通ボディ1つ ＋ 交換式チャーム蓋」

これが**コンセプトの核**であり、収益構造でもある。

```
        ┌──────────┐
        │  チャーム蓋  │ ← ハイタッチする手 / ドラゴンの爪 / 犬の耳 / 無地ミニマル
        │  （交換式）  │    共通のバヨネット（ひねりロック）マウント
        ├──────────┤
        │          │
        │  ボディ    │ ← ソフトシリコン外殻（Shore A 40-50、マット、握れる）
        │  約400mL   │    左ポケットに入る 約55 × 110 × 30mm、空重量 60g以下
        │          │
        │ ┌──────┐ │
        │ │バリア  │ │ ← 交換式インナーライナー（EVOH多層 or BOS互換）
        │ │ライナー │ │    ＝消耗品サブスクの本体。洗う問題も同時に解決
        │ └──────┘ │
        └──────────┘
```

**なぜ交換式蓋が効くか**
- ガチャ／コラボ／季節もので継続収益（Jibbitz・Bogg Bag チャームのモデル）
- 「かわいいが刺さらない層」を切り捨てずに済む（ドラゴンの爪＝男性・子ども、耳＝かわいい派、無地＝ミニマル派）
- 意匠権を蓋ごとに取れる＝コピー品への牽制になる
- ユーザーの「手 or ドラゴン or 耳」という迷いを、**選ばせずに全部出す**ことで解決できる

### 2-3. ハイタッチの仕掛け

- 蓋の掌面に**小さなネオジム磁石を完全に埋め込む（インサート成形で封止）**
  → 2人が手チャームを合わせると「タッ」と吸い付く。この一瞬の物理フィードバックが体験の核心
  → 同じ磁石が「蓋を本体側面に仮置きする」機能も兼ねる（片手で袋を入れるとき地味に効く）
- ⚠️ **安全性**: 磁石の誤飲は極めて危険。完全オーバーモールドで露出ゼロ、
  引張試験（チャームを引きちぎっても磁石が出ない）を必須要件にする。犬が噛む前提で設計する
- **色でシグナルを持たせる**（Yellow Dog Project に乗る、衝突させない）
  - 黄色の耳／爪 = 「うちの子はそっとしておいて」（既存の国際的慣習に準拠）
  - 緑 = 「あいさつOK、ハイタッチどうぞ」
  → かわいさだけでなく**存在理由**ができ、既存文化を上書きせず接続できる

### 2-4. 使い勝手の要件（既存品の不満から逆算）

日本のマナーポーチのレビューでは「臭い漏れ」「使いにくさ」「ファッション性のなさ」が繰り返し指摘されており、
より密閉されたマナーカプセルへの流出が起きている。片手開閉のためにばね口金を採用する製品も出ている。

| 要件 | 実装 |
|---|---|
| 片手で開く | ばね口金 or ワンプッシュのバヨネット。**ジッパーは却下**（両手必要・漏れる・壊れる） |
| 口が広い | 拾ったごみを**手で触らずに落とし込める**開口径。ここが街ごみ兼用の生命線 |
| 洗わなくていい | 交換式ライナー。「洗いにくい」を製品から消す |
| ポケット第一 | ぶら下げ前提にしない（そこは Awoo/Fable の激戦区）。低背ループは付けるが従 |
| 触っていたい | フィジェット品質。マットな手触り、適度な反発。**ポケットで触ってしまう=毎日持ち出す** |

### 2-5. ⚠️ 技術的な最大の落とし穴 — シリコンは防臭材ではない

**シリコンゴムはガス透過性が極めて高い。天然ゴムの約30倍、ブチルゴムの約400倍**
（[Silex 技術資料](https://www.silex.co.uk/technical-faq/gas-permeability/)）。
気体分離膜に使われる素材なので、**「全部シリコンのぷにぷにポーチ」は確実に臭う**。

対策:
1. **役割分離**: シリコン＝触感・意匠・衝撃吸収。**防臭は必ず別レイヤー**が担う
2. **バリア材**: EVOH（臭い・香気のバリア性に優れ、それ自体がほぼ無臭）を多層ライナーに使う
   （[TAPPI 資料](https://www.tappi.org/content/enewsletters/eplace/2004/27-1armstrong.pdf)）。
   または BOS 互換の多層フィルムを消耗品として採用し、自社は容器に徹する（開発費が一番安い）
3. **漏れるのは壁ではなく閉じ口**: リップシール／Oリングを圧縮するひねりロック、
   またはロールトップ＋磁石。ジッパーは論外
4. 外殻に低透過素材を使うならブチルゴム系・TPU も候補（ただし触感と両立しにくい）

### 2-6. 表示・法務の注意

- 「消臭」「防臭」「抗菌」は根拠が必要。景表法では**合理的根拠のない効果・性能表示は優良誤認**とみなされる
- 抗菌の SIAA マークは JIS Z 2801 の試験報告書（JNLA 付）が必要。
  「食中毒対策」「ウイルス対策」等の疾病関連表現は使用不可
  （[SIAA 広告表記ガイドライン](https://www.kohkin.net/dcms_media/other/K32.pdf) / [解説](https://www.calmic.co.jp/useful/siaa_mark/)）
- → 試験前は「臭わない」と書かない。**「BOS等の防臭袋がそのまま入る設計」と書くのが安全かつ正直**

| フェーズ | 期間/費用の目安 | やること | 合否判定 |
|---|---|---|---|
| **0. 自分で使う** | 2週間 / 〜5万円 | 3Dプリント原型＋シリコン注型（Dragon Skin等）で蓋3種。実際の散歩で持ち歩く | **10日目以降も左ポケットに入れているか**。ここで落ちたら作らない |

## 4. リスクと、正直な弱点

1. **臭い** — シリコン単体では必ず失敗する（§2-5）。ここを外すとレビューで即死
2. **コールドスタート** — ハイタッチは2人揃わないと成立しない。
   対策: 2個パック販売／「もう1個は誰かにあげる用」の同梱、ドッグラン・ドッグカフェ・ペット可マンション単位で面で配る、
   **そして何より N=1 でも成立する価値（フィジェット・かわいさ・実用）を単体で持たせる**
3. **コピー** — 3ヶ月で類似品が出る前提。**守るのは意匠権と儀式の名前とコミュニティ**であって、機能ではない
4. **「うんち」の見た目問題** — バッグに付けたいものと、うんちを入れるものは、心理的に相反する。
   だから **ライナー交換式（中身は使い捨て）＝本体は汚れない** という設計・訴求が効く
5. **日本ではBOSが既に安い** — 「臭わないこと」で戦わない

---

## 5. 一行でいうと

> **うんち袋ホルダーではなく、「街をちょっときれいにする人の携帯灰皿」を作る。**
> 蓋がチャームで、チャームがハイタッチ面で、交換できる。
> 中は使い捨てライナー。防臭はライナーが担い、シリコンは手触りだけを担う。
