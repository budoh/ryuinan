# 携帯ごみポーチ × ハイタッチチャーム — 市場リサーチと製品コンセプト

調査日: 2026-08-02

## 0. 出発点（アイデアの整理）

- 街でごみを拾いたいが「持ち歩くのが億劫」で結局拾わない、という自分の実体験が起点
- 左ポケットに入るサイズ。ゴムっぽい / シリコンっぽい、握れる手触り
- 蓋・チャームが「ハイタッチの手」「犬の耳」
- 持ち主同士が出会ったらチャームでハイタッチできる
- 「犬を飼っています」というさりげないアピールになる
- 自分が拾った街のごみも、犬のうんちも、両方入る
- **街ごみのときはポケット、うんちのときはカラビナで吊る** — 中身によって持ち方を変えたい

**結論の先出し**: 入れ物としては既存品が山ほどある。チャームも既にある。
だが「街ごみ＋犬のうんち兼用」×「持ち主同士のインタラクション」の組み合わせは
直接の競合が見つからなかった。**守れるのは容器ではなく、儀式（ritual）とブランド**。

## 2. 作るとしたら — 製品コンセプト

### 2-1. ポジショニング（これが一番大事）

**「うんち袋ホルダー」として売ってはいけない。**

理由は3つ:
1. カテゴリが価格競争済み。中国OEMが即コピーできる
2. 「うんち」ブランディングだと、バッグに付けて見せたくない＝チャーム戦略と矛盾する
3. TAMが犬の飼い主に閉じる

代わりに **「令和の携帯灰皿」＝街をちょっときれいにする人のためのポケットごみ箱** として置く。

### 2-1-a. コンセプトの核 — 「ゴミ拾ってる人tribe」の握手

売っているのは容器ではない。**すでに存在しているのに、お互いを認識する手段がない部族**に、
挨拶の作法を渡している。

```
   ゴミ拾ってる人 tribe  →  すれ違う  →  ハイタッチ
        （既に居る）      （今は素通り）   （これを売る）
```

**この部族は作る必要がない。もう居る。**
- [グリーンバード](https://ja.wikipedia.org/wiki/%E3%82%B0%E3%83%AA%E3%83%BC%E3%83%B3%E3%83%90%E3%83%BC%E3%83%89)は2002年に原宿で始まり、
  現在は国内外80チーム・年間参加者3万人規模（[参考](https://spaceshipearth.jp/greenbird/)）
- [プロギング](https://plogging.jp/)のランナー、早朝に自分の店の前を掃く人、
  犬の散歩ついでに拾う人、通勤路で吸い殻を拾う人

**彼らに共通する欠落は「道具」ではなく「認識」**。
拾っている人同士がすれ違っても、お互いが同類だと分からないまま通り過ぎている。
バッグチャームが「言葉にしなくても好きが伝わる、アイデンティティの象徴」として機能している
（[SPUR](https://spur.hpplus.jp/fashion/topics/kYEJqQ/)）のと同じ原理を、
善意ではなく**所属**に対して使う。

**設計上の帰結**:
- **手（掌）の面はどの蓋にも必ずある** — ハイタッチ面として機能上必須だから、結果的に**部族の共通記号が自動的に定数になる**。
  耳をつけても無地にしても、掌の平面とシルエットは変わらない。機能が記号を固定してくれる
- **犬の耳は下位バッジ**。「拾う人である」が第一階層、「かつ犬を飼っている」が第二階層
- ハイタッチの相手は犬の飼い主に限らない。**拾う人なら誰でも**

### 2-1-b. 敵は「ダサさ」— ボランティアにならずに拾えること

既存のゴミ拾いは**イベント型**で、そこにダサさが構造的に埋まっている。
揃いのビブス、トング、軍手、透明のゴミ袋、そして集団。全部が「作業着」であり「行事の道具」。

**ダサさの正体は5つ**:

| イベント型（今のゴミ拾い） | 日常型（作りたいもの） |
|---|---|
| ビブスを着る＝**変身する**。終わったら脱ぐ | **着替えない。持ち物が1個増えるだけ** |
| 集まってやる／時間を確保する（1時間） | ひとりで、ついでに、**3秒で** |
| トング・軍手・透明袋＝**支給された作業着** | **私物・愛用品。むしろ人に見せたいもの** |
| 「良いことしてます」が誰にでも**読める** | **仲間にしか読めない**（§2-3） |
| 団体に**所属する**（ロゴを背負う） | 誰にも所属しない。部族には自然に入っている |

> **敵は「誰も拾わないこと」ではない。「拾うために一度ボランティアにならなければいけないこと」。**
> 1時間だけ善人の格好をして、終わったら脱ぐ。これが日常化しない理由そのもの。

**したがって、絶対にやってはいけないこと**:
- ユニフォーム・ビブス・ロゴTシャツを作る（イベント型に戻る）
- 「参加者」「メンバー登録」「活動報告」の仕組みを持つ（所属を強制した瞬間に日常でなくなる）
- トングを製品化する（作業の道具に見える。§2-4 の「手の蓋で押し込む」で代替する）

**先例: 善行が「ただの持ち物」になった3つ**

| | 転換前 | 転換後 | 効いたもの |
|---|---|---|---|
| 携帯灰皿 | 喫煙者のマナー啓発 | 普通の小物。[グッドデザイン賞商品](https://sakidori.co/article/14856)も出る | **デザインと所有欲** |
| エコバッグ | 意識高い系のトートバッグ | 全員が持っている | レジ袋有料化（2020年7月）＋**持ちたくなる商品化** |
| マイボトル | 環境意識の表明 | ただの水筒 | 保温性能という**実利**＋デザイン |

共通するのは、**善意ではなく実利か虚栄心で買える物になった瞬間に、行動が日常化した**こと。

> **設計上の勝利条件: 「かわいいから／気持ちいいから買った。拾うのはついで」で成立すること。**
> 良心に訴えて買わせた時点で、それはイベント型の延長でしかない。

**主役は街ごみ。犬は流通チャネルであって、アイデンティティではない。**
- 製品名にも訴求にも「犬」「うんち」を一切出さない。出した瞬間にTAMが閉じ、バッグに付けたくなくなる
- 犬の飼い主は**ビーチヘッド**（毎日歩く・すでに持ち歩く習慣がある・可処分所得が高い）。
  市場は追い風: 犬の飼育頭数 682万頭で下げ止まり（[ペットフード協会 2025年調査](https://midori-ikimono.com/2025/12/22/petfoodkyokai2025/)）、
  ペット関連市場は2025年度 1兆9,257億円 → 2027年度に2兆円超の予測（[矢野経済研究所](https://www.yano.co.jp/press-release/show/press_id/3906)）
- **犬を飼っていない層こそが本命の広がり**: 喫煙者（携帯灰皿の置き換え）、ランナー・[プロギング](https://plogging.jp/)層、
  子連れの親（お菓子の包み・使用済みおしぼり）、キャンプ・フェス、通勤者。犬の飼い主より母数がはるかに大きい
- ハイタッチの相手も「犬の飼い主同士」に限定しない。**「拾う側の人間だ」という記号**にすれば、
  犬連れでない人ともハイタッチが成立する。犬の耳はその中の1スキンに過ぎない

### 2-2. 構造 — 「共通ボディ1つ ＋ 交換式チャーム蓋」

これが**コンセプトの核**であり、収益構造でもある。

```
        ┌──────────┐
        │  チャーム蓋  │ ← ハイタッチする手 / 犬の耳 / 無地ミニマル
        │  ＋吊り金具  │    **ここにカラビナが付く（本体側ではない）**
        │  （交換式）  │    共通のバヨネット（ひねりロック）マウント
        ├──────────┤
        │ ≡≡≡≡≡≡≡≡ │
        │  ボディ    │ ← ソフトシリコン外殻（Shore A 40-50、マット、握れる）
        │ 蛇腹で伸縮  │    **空: 約55 × 60 × 25mm（左ポケットで存在感ゼロ）**
        │ ≡≡≡≡≡≡≡≡ │    **満: 約55 × 150mm / 約600mL（350mL缶が入る）**
        │ ┌──────┐ │
        │ │バリア  │ │ ← 交換式インナーライナー（EVOH多層 or BOS互換）
        │ │ライナー │ │    ＝消耗品サブスクの本体。洗う問題も同時に解決
        │ └──────┘ │
        └──────────┘
```

**なぜ蛇腹（ベローズ）にするか — ここが街ごみ対応の核心**

固定容量にすると「ポケットに入るサイズ」と「缶や空きボトルが入る容量」が両立しない。
400mL固定（リッチェルのマナーカプセルと同容量）では 350mL缶すら入らない。
シリコンは折り畳み構造が得意な素材なので、**空のときは潰れて薄く、入れると伸びる**設計にする。
Turdlebag がロールトップで容量可変にしているのと同じ発想を、素材の強みに寄せた形。

**なぜ交換式蓋が効くか**
- ガチャ／コラボ／季節もので継続収益（Jibbitz・Bogg Bag チャームのモデル）
- 「かわいいが刺さらない層」を切り捨てずに済む（耳＝かわいい派、手＝ニュートラル、無地＝ミニマル派）
- 意匠権を蓋ごとに取れる＝コピー品への牽制になる
- 「手 or 耳」という迷いを、**選ばせずに全部出す**ことで解決できる
- **同じ本体で2台持ちができる**（街ごみ用＝ポケット、うんち用＝吊り）。蓋を変えれば見分けもつく

**持ち方は2モード — 中身で切り替える**

| 中身 | 持ち方 | 理由 |
|---|---|---|
| 街ごみ（吸い殻・包み紙） | **ポケット** | 軽い・においが弱い・突発的に拾うので手元にあってほしい |
| 犬のうんち | **カラビナで吊る**（リード / バッグ / ベルトループ） | 重い・においがある・**脚に当たっていてほしくない** |

だから **吊り金具は本体ではなく蓋（チャーム）側に付ける**。これで1つの部品が3役を兼ねる:

1. **握って回す**グリップ（開閉）
2. **ハイタッチする面**（磁石入り）
3. **吊り下げの支点**（カラビナが通る）

副次効果として、**吊っているときはチャームが一番よく見える位置に来る**。
「犬飼ってます」のアピールも、ハイタッチの相手を見つける手がかりも、
**一番必要になる犬モードのときに、自動的に可視化される**。ポケットに入れている街ごみモードでは
見えなくてもいい（そのときは自分のための道具でしかない）。

**吊るときの実装上の注意**
- 業界的には「ぶら下がって揺れる」のは嫌われている。Awoo は背面スロットでリードに密着させる
  「dangle-free」を売りにし、Fable はリードに沿って平らに載せている
- なので**ただ吊るすだけでは既存品に負ける**。短ストラップでリードに沿わせる／スイベル付きカラビナで
  ねじれを止める／本体側面の磁石でリードに貼り付けて揺れを殺す、のいずれかは必須
- うんち入りで200〜400gが振れるので、支点は高く・体に近く

### 2-3. ハイタッチの仕掛け

- 蓋の掌面に**小さなネオジム磁石を完全に埋め込む（インサート成形で封止）**
  → 2人が手チャームを合わせると「タッ」と吸い付く。この一瞬の物理フィードバックが体験の核心
  → 同じ磁石が「蓋を本体側面に仮置きする」機能も兼ねる（片手で袋を入れるとき地味に効く）
- ⚠️ **安全性**: 磁石の誤飲は極めて危険。完全オーバーモールドで露出ゼロ、
  引張試験（チャームを引きちぎっても磁石が出ない）を必須要件にする。犬が噛む前提で設計する
- **色でシグナルを持たせる**（Yellow Dog Project に乗る、衝突させない）
  - 黄色の耳 = 「うちの子はそっとしておいて」（既存の国際的慣習に準拠）
  - 緑 = 「あいさつOK、ハイタッチどうぞ」
  → かわいさだけでなく**存在理由**ができ、既存文化を上書きせず接続できる

**設計原則: シグナルは部外者に読めてはいけない**

日本では「良いことをしているアピール」は逆風になる（偽善だと思われたくない、意識高い系に見られたくない）。
だから **記号は仲間にだけ解ける低コントラストにする**。

- 文字を入れない。「ECO」「CLEAN」「SDGs」等のワードは一切載せない
- 部外者には**ただのかわいいチャーム**にしか見えない。仲間には**メンバーの印**に見える
- これは制約ではなく品質条件。読めてしまう記号は、この部族では機能しない

**所作は「触らない」がデフォルト — ヤエー型にする**

日本人は見知らぬ人とハイタッチしない。だから**接触は必須にしない**。
基本は**すれ違いざまに軽く手を挙げる**だけ。触りたい人だけが触る。

| レベル | 所作 | 誰向け |
|---|---|---|
| 0 | 目が合う。何もしない | それでいい。強制しない |
| **1（既定）** | **軽く手を挙げる**（ヤッホー的な会釈） | **全員** |
| 2 | チャーム同士を合わせる（磁石で「タッ」） | やりたい人だけ |

**先例: バイクの「ヤエー」**
すれ違うライダー同士が手を挙げて挨拶する慣習。2003年頃に2ちゃんねるの "Yeah!" の綴り間違い
"Yaeh!" から広まったとされ、**団体もユニフォームも登録もないのに定着している**
（[まっぷる](https://www.mapple.net/original/532489/) / [バイク王](https://www.8190.jp/bikelifelab/useful/beginners/yaeh/)）。
挨拶であると同時に「お互い気をつけて」の意味も持つ。**これがこの製品の所作の完全な先例**。
登山者同士の「こんにちは」も同型（活動を共有する見知らぬ人同士が挨拶し、誰も変だと思わない）。

**この設計がなぜ強いか — 失敗のコストがゼロ**
- ハイタッチは**相手が応じないと気まずい**。片手を出して空振りするのは社会的リスクが高い
- 手を挙げるだけなら、**返ってこなくても何も起きない**（髪を直しただけの顔ができる）
- リスクがゼロの所作は普及する。**普及しない儀式は、たいてい失敗が痛いから普及しない**

**役割分担が明確になる**
- **チャーム = 識別**（誰が仲間か分かる）← 製品が担う
- **手を挙げる = 挨拶**（所作自体は無料・無道具）← 文化が担う
- 磁石は「レベル2をやりたい人へのご褒美」に格下げ。ただし蓋を本体に仮置きする機能は残るので採用は続行

判定基準は変わらない: **仕込みなしで自然発生するか**。説明が要る所作なら、その時点で負けている。

### 2-4. 街ごみ側の設計要件 — 犬のうんちとは「別の問題」

ここを甘く見ると製品が破綻する。**犬のうんちは「必ず袋に入った・柔らかい・形が一定・100〜300g」。街ごみは全部その逆。**

| | 犬のうんち | 街ごみ |
|---|---|---|
| 形 | 袋詰め済み・柔らかい | 不定形・硬い・かさばる |
| 濡れ | 袋が防いでくれる | **飲み残しがそのまま垂れる**（紙コップ、飲みかけ缶） |
| 温度 | 常温 | **吸い殻は熱を持っていることがある** |
| 頻度 | 1日1〜2回、確実に発生 | 気まぐれ・突発的 |
| 素手で触りたくなさ | 袋越しなので許容範囲 | **極めて高い** |

**追加で必要になる4要件**

1. **液密であること** — うんちは袋が防いでくれるが、街ごみは液体が直接入る。
   **犬用マナーポーチより要求水準が高い。** 底は継ぎ目のない一体成形、閉じ口はリップシール圧縮
2. **吸い殻と熱** — 街ごみの最頻出物。シリコンは耐熱200℃前後あるので、**防臭では不正解だった素材が、ここでは正解**になる。
   ただし火のついたままの吸い殻（先端は数百℃）には耐えない。「完全に消してから」を前提にしつつ、
   喫煙者向けにはアルミ蒸着ライナーを別グレードで用意するのが現実解（携帯灰皿が内側にアルミを使うのと同じ理由）
3. **鋭利物** — 割れたガラス、プルタブ。ソフトシリコンは貫通に弱い。
   **「ガラスは対象外」と明記する**のを推奨（耐摩耗インナーを足すより、過剰設計を避けるほうが正しい）
4. **触らずに入れる** — 口を広く、リムを硬く。しゃがんで**ポーチの口を地面に当てて押し込める**形状に。
   さらに踏み込むなら **手の蓋を「押し込むヘラ」として使えるようにする**。
   蓋を外す → 掌の面で吸い殻や包み紙を口の中へ押し込む → 蓋を戻す。
   「かわいいから手」ではなく「**手だから触らずに済む**」になり、造形と機能が一致する

**現実的なターゲット**: 吸い殻／お菓子の包み／キャップ／レシート／ティッシュ／マスク／缶1本まで。
**対象外と明言する**: 大きいペットボトル、傘、ガラス。ここを欲張ると全部が中途半端になる。

### 2-5. 使い勝手の要件（既存品の不満から逆算）

日本のマナーポーチのレビューでは「臭い漏れ」「使いにくさ」「ファッション性のなさ」が繰り返し指摘されており、
より密閉されたマナーカプセルへの流出が起きている。片手開閉のためにばね口金を採用する製品も出ている。

| 要件 | 実装 |
|---|---|
| 片手で開く | ばね口金 or ワンプッシュのバヨネット。**ジッパーは却下**（両手必要・漏れる・壊れる） |
| 口が広い | 拾ったごみを**手で触らずに落とし込める**開口径。ここが街ごみ兼用の生命線 |
| 洗わなくていい | 交換式ライナー。「洗いにくい」を製品から消す |
| 2モードの両立 | ポケットでは薄く潰れ、吊るときは揺れない。**どちらかの最適化に倒すと片方が死ぬ**（§2-2） |
| 触っていたい | フィジェット品質。マットな手触り、適度な反発。**ポケットで触ってしまう=毎日持ち出す** |

### 2-6. ⚠️ 技術的な最大の落とし穴 — シリコンは防臭材ではない

**シリコンゴムはガス透過性が極めて高い。天然ゴムの約30倍、ブチルゴムの約400倍**
（[Silex 技術資料](https://www.silex.co.uk/technical-faq/gas-permeability/)）。
気体分離膜に使われる素材なので、**「全部シリコンのぷにぷにポーチ」は確実に臭う**。

対策:
1. **役割分離**: シリコン＝触感・意匠・衝撃吸収。**防臭は必ず別レイヤー**が担う
2. **バリア材**: EVOH（臭い・香気のバリア性に優れ、それ自体がほぼ無臭）を多層ライナーに使う
   （[TAPPI 資料](https://www.tappi.org/content/enewsletters/eplace/2004/27-1armstrong.pdf)）。
   または BOS 互換の多層フィルムを消耗品として採用し、自社は容器に徹する（開発費が一番安い）
3. **漏れるのは壁ではなく閉じ口**: リップシール／Oリングを圧縮するひねりロック、
   またはロールトップ＋磁石。ジッパーは論外
4. 外殻に低透過素材を使うならブチルゴム系・TPU も候補（ただし触感と両立しにくい）

### 2-7. 表示・法務の注意

- 「消臭」「防臭」「抗菌」は根拠が必要。景表法では**合理的根拠のない効果・性能表示は優良誤認**とみなされる
- 抗菌の SIAA マークは JIS Z 2801 の試験報告書（JNLA 付）が必要。
  「食中毒対策」「ウイルス対策」等の疾病関連表現は使用不可
  （[SIAA 広告表記ガイドライン](https://www.kohkin.net/dcms_media/other/K32.pdf) / [解説](https://www.calmic.co.jp/useful/siaa_mark/)）
- → 試験前は「臭わない」と書かない。**「BOS等の防臭袋がそのまま入る設計」と書くのが安全かつ正直**

| **2. 金型** | 2〜3ヶ月 | LSR単一キャビ金型は $500〜5,000/型が相場（部品構成的に本体・蓋・ライナーで合計 $8k〜20k を見込む）。[参考](https://www.accio.com/plp/silicone-injection-molding-cost) | 1万個で$10k金型なら1個あたり約150円 |

### 3-1. 最初の10個をどう作るか — 結論: 自宅にシリコン注型ラボを作る

**推奨: 外注しない。初期6万円で「何度でも作れる状態」を買う。**

理由は3つ。

1. **この製品は手触りが全て。** 硬度、肉厚、蛇腹のヘタリ、握ったときの反発、蓋を回すトルク。
   これは図面では決まらない。**触って直した回数が、そのまま品質になる。** だから買うべきは「10個」ではなく「回数」
2. **サイクルタイムが桁違い。** 外注は1周 2〜3週間 × 数万円。自宅は1周 2〜3日 × 数千円。
   10周まわす前提なら、外注は数十万円と半年、自宅は材料費3万円と1ヶ月
3. **資産が残る。** 装置とスキルは次のプロダクトでも使える。外注は毎回ゼロから

**初期セットアップ（買い切り）**

| はかり・混合カップ・離型剤・顔料 | — | ¥5,000 |
| **合計** | | **¥51,000〜61,000** |

- CADは **Fusion 360 の個人利用（無料）** で足りる。コードが書けるなら習得は問題にならない
- 真空脱泡機は**最初は買わない**。気泡は叩き出しと圧力鍋で当面しのげる。必要になってから
- ランニングは1個あたりシリコン50〜80g ＝ **500〜800円**。10個で1万円弱

**期間: 約4週間**

ただし**約254円/cm³**なので、体積のある本体まで刷ると1個1万円級になり10個で10万円。
**学びの単価が高すぎるので本体は自作する。**

**やってはいけないこと**

- ❌ **いきなり簡易金型を切る**（国内で[簡易型 数万〜十万円台](http://tpm.co.jp/sidoujyou/602/)）。

**金型を切るのは3手目**

### 3-2. 「人生に沿うやり方」— 10個は試作品ではなく、最初の10人

ここが一番大事なところ。**毎日の犬の散歩が、そのままテストループになる。**

```
夜: 注型して寝る  →  朝: 散歩で使う  →  夜: 直してまた注型
```

週末にまとめてやる「作業」になった時点で続かない。**生活のリズムに乗る作り方だけが、中長期で回る。**

そして**10個を「自分用の試作」にしない**。1個を自分用にして、**残り9個は配る前提で作る**。
そうすると Phase 0 と Phase 1 が地続きになり、
**試作しながらコールドスタート問題（§4-2）を同時に解いている**状態になる。

- 作る過程を公開しながら作る。10個作る記録そのものがコンテンツになり、配る相手も同時に集まる
- 配布先は §2-1-a の通り、部族が既にいる場所（グリーンバードのチーム、プロギング、ドッグラン）
- **9人が「もう1個ほしい、あの人にあげたい」と言ったら、その時点で勝ち筋が見えている**

**単価の目安（ラフ）**: FOB 800〜1,100円 → 上代 4,800円（蓋1個付き）／
交換蓋 1,200〜1,800円／ライナー12枚 980円のサブスク。
1,000円台のマナーポーチと同じ土俵に降りない価格設定にすること。

## 4. リスクと、正直な弱点

1. **臭い** — シリコン単体では必ず失敗する（§2-6）。ここを外すとレビューで即死
2. **コールドスタート** — ハイタッチは2人揃わないと成立しない。
   ただし**部族はゼロから作らなくていい**（§2-1-a）。既存の集まりに配れば初日から密度が出る。
   対策: グリーンバードのチーム（国内外80チーム・年間3万人）、プロギングイベント、ランニングクラブ、
   ドッグラン・ドッグカフェ・ペット可マンションなど**面（コミュニティ）単位で配る**。
   2個パック／「もう1個は誰かにあげる用」の同梱。
   **そして何より N=1 でも成立する価値（フィジェット・かわいさ・実用）を単体で持たせる**
3. **コピー** — 3ヶ月で類似品が出る前提。**守るのは意匠権と儀式の名前とコミュニティ**であって、機能ではない
4. **「うんち」の見た目問題** — バッグに付けたいものと、うんちを入れるものは、心理的に相反する。
   だから **ライナー交換式（中身は使い捨て）＝本体は汚れない** という設計・訴求が効く
5. **日本ではBOSが既に安い** — 「臭わないこと」で戦わない
6. **偽善に見えるリスク（日本特有）** — 「拾ってます」が可視化されすぎると逆効果になる。
   §2-3 の「部外者に読めない記号」が効かなければ、**部族の記号ではなく自慢の記号**になって死ぬ。
   ここは日本市場に固有の失敗モードなので、海外事例をそのまま持ち込めない

## 5. 一行でいうと

> **売っているのは容器ではなく、「ゴミ拾ってる人tribe」の握手。**
> 部族はもう存在していて、お互いを認識する手段だけがない。そこにハイタッチを渡す。
>
> 器としては「街をちょっときれいにする人の携帯灰皿」。
> 空のときは潰れて左ポケットに消え、入れると蛇腹で伸びて缶1本まで飲み込む。
> 街ごみはポケット、うんちはカラビナで吊る。**吊り金具は蓋側**なので、
> 蓋がチャームで、ハイタッチ面で、グリップで、吊り下げの支点。1部品が4役。
> 交換できる。
> 中は使い捨てライナー。防臭はライナーが担い、シリコンは手触りと耐熱だけを担う。
>
> 主役は街ごみ。犬のうんちも入る。犬の飼い主は最初の100人であって、顧客像そのものではない。
